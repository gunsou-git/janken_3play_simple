# じゃんけん（3人対戦）

ブラウザで遊べる、あなた＋コンピューター2人の3人じゃんけんです。
HTML と JavaScript（jQuery）で作ったシンプルな練習用アプリです。

## 遊び方

1. `index.html` をブラウザで開く
2. 「グー」「チョキ」「パー」のボタンから自分の手を選ぶ
3. 相手1・相手2の手がランダムに決まり、3人の手と勝敗が表示される

## 勝敗のルール

| 3人の手 | 結果 |
| --- | --- |
| 3人とも同じ手 | あいこ |
| グー・チョキ・パーが全部出た | あいこ |
| 2種類の手が出て、自分が勝つ側 | あなたの勝ち |
| 2種類の手が出て、自分が負ける側 | あなたの負け |

判定の考え方：自分の手に勝つ手（グーならパー、チョキならグー、パーならチョキ）を相手のどちらかが出していれば「負け」、いなければ「勝ち」としています。

## 使用技術

- HTML5
- JavaScript
- jQuery 3.4.1（Google Hosted Libraries から読み込み）

## ファイル構成

```
janken_3play_simple/
├── index.html    # 画面（ボタンと結果表示）
└── js/
    └── test.js   # じゃんけんの処理（手の決定・勝敗判定・表示）
```

## 実行方法

ビルドやインストールは不要です。

```bash
git clone https://github.com/gunsou-git/janken_3play_simple.git
cd janken_3play_simple
open index.html   # Windows の場合は start index.html
```

※ jQuery をインターネット経由で読み込むため、オンライン環境で開いてください。
